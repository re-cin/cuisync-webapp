How tags work

  • Automatic tags are made from each dish's data: the region, cooking actions (Grilled, Steamed…), main protein, dish type from the title, Spicy and Vegetarian.
  • To change an automatic tag, edit the dish's ingredients or cooking actions.
  • Custom tags are added on a dish's form, comma-separated (e.g. street food, festive).
  • All tags show in “Search by tag” on the public site.
